# Notion 知识库还原计划

## 已确认的产品边界

- Notion 是唯一内容来源；同步覆盖 WordPress 中受管正文。
- 授权同步范围内内容允许公开；图片和附件默认本地保存。
- 子页面独立发布，保留层级和内部链接。
- 确认来源删除才移入回收站；读取失败与失去权限不作为删除证据。
- 默认目标为 10 分钟定时增量同步，手动同步保留，已有 Webhook 兼容。
- 保留现有功能，小步合并重复实现，暂停外围功能扩展。

以上是目标，不代表当前版本全部实现。

## 本批次公式改动

- 开启 KaTeX 抛错，在成功后才标记 rendered。
- 解析失败显示完整文本源，禁用 HTML 插入，允许修正后重试。
- 化学式优先读取源属性并跳过已经成功渲染的元素。
- 新增测试使用插件自带 KaTeX 与 mhchem，无网络依赖。

## 第二批开发进展

- 字段映射页增加内嵌数据库默认布局：兼容自动识别、表格、画廊、列表、看板；保存后重新同步生效。
- 渲染器支持显式视图优先于默认配置，保留旧标题识别行为。后台当前提供全局默认值，尚无逐个数据库配置入口。
- 增加列表视图；四种布局的条目标题提供来源链接。目前链接仍使用 Notion URL，尚未实现对应 WordPress 页面链接解析。

- 元数据提取失败或缺少 DOM 扩展时仍保留来源链接；仅使用 HTTP(S) 绝对封面地址。不支持相对封面地址或自动判断浏览器中的 iframe 拒绝嵌入。
- 新增四项 PHP 呈现测试。真实 WordPress content-fixture 测试通过，测试脚本兼容改名目录及网络激活。

单元测试不替代真实 Notion 样本与 WordPress 浏览器对照。当前未完成最新实际知识库抽样、视图排序筛选和封面本地化、逐数据库配置、完整视觉与交付验收。
